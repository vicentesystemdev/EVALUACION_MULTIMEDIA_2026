### 1.1 Worktree de QA limpio (recomendado)

Revisar los PR en un **worktree o clon dedicado a QA**, no en la carpeta de trabajo habitual. Así no se modifican ni se descartan los cambios locales, archivos sin seguimiento o el stash del proyecto original.

```powershell
# Una sola vez, desde cualquier clon existente (no altera su árbol de trabajo):
git fetch origin --prune
git worktree add --detach D:\Unity\EVALUACION_MULTIMEDIA_2026_QA origin/develop

# Para cada PR, dentro del worktree de QA:
cd D:\Unity\EVALUACION_MULTIMEDIA_2026_QA

git fetch origin --prune
git switch --detach origin/<rama-del-PR>     # o: git fetch origin pull/<N>/head:qa/pr-<N>; git switch qa/pr-<N>
```

- Abrir **solo** esa carpeta en Unity Hub para la revisión. La primera importación genera `Library/` (lenta, ignorada por Git).
- No hacer commits en el worktree de QA. Si hace falta corregir algo, se pide al autor en el PR.
- Al terminar todas las revisiones, se puede retirar con `git worktree remove D:\Unity\EVALUACION_MULTIMEDIA_2026_QA` **solo si `git status` está limpio**.

### 1.3 Aislamiento y respaldo del progreso guardado (obligatorio antes de F4, R1–R7 y §4)

**Un worktree o clon distinto NO aísla el guardado.** `CGStore` escribe en `Application.persistentDataPath`, que Unity calcula a partir de `companyName` y `productName` de `ProjectSettings`, no de la carpeta del proyecto. Todos los worktrees, clones y el `.exe` de este proyecto comparten, por tanto, la misma carpeta:

```text
%USERPROFILE%\AppData\LocalLow\DefaultCompany\CAMPUS_GLITCH_TEMP\
    campus_glitch_save_v1.json        ← progreso
    campus_glitch_save_v1.json.bak    ← copia que el propio juego sobrescribe en cada guardado (no sirve como respaldo de QA)
```

No cambiar `ProjectSettings` para aislar el guardado: está fuera del alcance de estos PR. En su lugar, respaldar fuera de esa carpeta y restaurar al terminar con el procedimiento siguiente (PowerShell 5.1 o posterior, con Unity sin Play y el `.exe` cerrado).

**Principios de seguridad del procedimiento**

- Solo se tocan tres archivos concretos de la carpeta de guardado: `campus_glitch_save_v1.json`, `.json.bak` y `.json.tmp`. Nunca se usan comodines ni se borra la carpeta con contenido.
- El respaldo se crea en una carpeta **nueva** con fecha y hora; si ya existiera, el paso 1 se detiene en lugar de sobrescribirla.
- El paso 1 distingue tres estados y los registra en `manifiesto.json` dentro del respaldo:
  - `SIN_CARPETA`: no existe la carpeta de guardado.
  - `CARPETA_SIN_JSON`: existe la carpeta, pero no `campus_glitch_save_v1.json`.
  - `CON_JSON`: existe un JSON y se puede leer como JSON válido. Si el JSON existe pero no es válido, el paso 1 se detiene: **no hacer QA** y copiar la carpeta a mano.
- Cada archivo respaldado se verifica comparando su hash SHA-256 con el del original.
- El paso 3 **no borra nada** hasta comprobar que el manifiesto existe, es legible y que cada archivo respaldado sigue presente con el mismo hash.
- Cada bloque está envuelto en `. { … }`: si una comprobación falla (`throw`), el bloque se detiene completo y las variables (`$bk`, `$save`) quedan disponibles en la sesión.

**Paso 0 — Variables** (ejecutar en la misma consola antes del paso 1 y del paso 3):

```powershell
$save   = Join-Path $env:USERPROFILE 'AppData\LocalLow\DefaultCompany\CAMPUS_GLITCH_TEMP'
$name   = 'campus_glitch_save_v1.json'
$bkRoot = Join-Path $env:USERPROFILE 'Documents'
$files  = @($name, "$name.bak")            # archivos que se respaldan y restauran
```

**Paso 1 — Respaldo antes de la QA** (no modifica la carpeta de guardado):

```powershell
. {
  $bk = Join-Path $bkRoot ('CG_QA_backup_' + (Get-Date -Format 'yyyyMMdd_HHmmss'))
  if (Test-Path -LiteralPath $bk) { throw "Ya existe $bk; espera un segundo y repite. No se sobrescribe ningún respaldo." }
  New-Item -ItemType Directory -Path $bk -ErrorAction Stop | Out-Null

  $jsonPath = Join-Path $save $name
  if (-not (Test-Path -LiteralPath $save -PathType Container)) { $estado = 'SIN_CARPETA' }
  elseif (-not (Test-Path -LiteralPath $jsonPath -PathType Leaf)) { $estado = 'CARPETA_SIN_JSON' }
  else {
    try { Get-Content -LiteralPath $jsonPath -Raw -ErrorAction Stop | ConvertFrom-Json -ErrorAction Stop | Out-Null }
    catch { throw "El guardado existe pero no es un JSON legible: copia $save a mano y NO hagas la QA. Detalle: $_" }
    $estado = 'CON_JSON'
  }

  $hashes = @{}
  foreach ($f in $files) {
    $src = Join-Path $save $f
    if (Test-Path -LiteralPath $src -PathType Leaf) {
      Copy-Item -LiteralPath $src -Destination (Join-Path $bk $f) -ErrorAction Stop
      $h1 = (Get-FileHash -LiteralPath $src -Algorithm SHA256 -ErrorAction Stop).Hash
      $h2 = (Get-FileHash -LiteralPath (Join-Path $bk $f) -Algorithm SHA256 -ErrorAction Stop).Hash
      if ($h1 -ne $h2) { throw "La copia de $f no coincide con el original." }
      $hashes[$f] = $h2
    }
  }
  [pscustomobject]@{ estado = $estado; carpeta = $save; fecha = (Get-Date -Format s); hashes = $hashes } |
    ConvertTo-Json | Set-Content -LiteralPath (Join-Path $bk 'manifiesto.json') -Encoding UTF8 -ErrorAction Stop
  "Estado original: $estado"; "Respaldo: $bk  (anotar esta ruta en el registro de QA)"
  Get-ChildItem -LiteralPath $bk
}
```

**Paso 2 — Preparar el progreso de prueba:** editar `campus_glitch_save_v1.json` (o crearlo, creando la carpeta si no existía) solo con el juego detenido.

**Paso 3 — Restauración al terminar la QA.** En una consola nueva, repetir el paso 0 y fijar antes `$bk = '<ruta anotada>'`.

```powershell
. {
  # 3a) Validaciones: hasta aquí no se ha borrado nada
  if (-not $bk) { throw 'La variable $bk está vacía: no se restaura ni se borra nada.' }
  $manPath = Join-Path $bk 'manifiesto.json'
  if (-not (Test-Path -LiteralPath $manPath -PathType Leaf)) { throw "No existe $manPath; no se restaura ni se borra nada." }
  $man = Get-Content -LiteralPath $manPath -Raw -ErrorAction Stop | ConvertFrom-Json -ErrorAction Stop
  if ($man.estado -notin 'SIN_CARPETA', 'CARPETA_SIN_JSON', 'CON_JSON') { throw "Estado desconocido '$($man.estado)'; no se modifica nada." }
  if ($man.carpeta -ne $save) { throw "El manifiesto pertenece a otra carpeta ($($man.carpeta)); no se modifica nada." }
  $respaldados = @($man.hashes.PSObject.Properties | ForEach-Object { $_.Name })
  foreach ($f in $respaldados) {
    $copia = Join-Path $bk $f
    if (-not (Test-Path -LiteralPath $copia -PathType Leaf)) { throw "Falta la copia $copia; no se modifica nada." }
    if ((Get-FileHash -LiteralPath $copia -Algorithm SHA256 -ErrorAction Stop).Hash -ne $man.hashes.$f) { throw "La copia $f no coincide con el manifiesto; no se modifica nada." }
  }
  if ($man.estado -eq 'CON_JSON') {
    if ($respaldados -notcontains $name) { throw 'El manifiesto dice CON_JSON pero no hay JSON respaldado; no se modifica nada.' }
    Get-Content -LiteralPath (Join-Path $bk $name) -Raw -ErrorAction Stop | ConvertFrom-Json -ErrorAction Stop | Out-Null
  }

  # 3b) Restaurar: solo los tres archivos concretos de la ruta de guardado
  if ($respaldados.Count -gt 0 -and -not (Test-Path -LiteralPath $save -PathType Container)) {
    New-Item -ItemType Directory -Path $save -ErrorAction Stop | Out-Null
  }
  foreach ($f in $files) {
    $dst = Join-Path $save $f
    if ($respaldados -contains $f) {
      Copy-Item -LiteralPath (Join-Path $bk $f) -Destination $dst -Force -ErrorAction Stop       # vuelve el original
      if ((Get-FileHash -LiteralPath $dst -Algorithm SHA256).Hash -ne $man.hashes.$f) { throw "La restauración de $f no coincide." }
    } elseif (Test-Path -LiteralPath $dst -PathType Leaf) {
      Remove-Item -LiteralPath $dst -ErrorAction Stop                                         # no existía antes: lo creó la QA
    }
  }
  $tmp = Join-Path $save "$name.tmp"
  if (Test-Path -LiteralPath $tmp -PathType Leaf) { Remove-Item -LiteralPath $tmp -ErrorAction Stop }   # temporal del juego

  # 3c) Si originalmente no existía la carpeta, eliminarla solo si quedó vacía
  if ($man.estado -eq 'SIN_CARPETA' -and (Test-Path -LiteralPath $save -PathType Container)) {
    if (@(Get-ChildItem -LiteralPath $save -Force).Count -eq 0) { Remove-Item -LiteralPath $save -ErrorAction Stop; 'Carpeta de guardado eliminada (no existía antes y quedó vacía).' }
    else { "La carpeta $save contiene otros archivos (p. ej., Player.log del .exe); se conserva sin tocarlos." }
  }
  "Restaurado el estado original: $($man.estado)"
  if (Test-Path -LiteralPath $save) { Get-ChildItem -LiteralPath $save -Force }
}
```

**Cómo queda cada caso tras el paso 3**

| Estado original | Resultado de la restauración |
|---|---|
| `CON_JSON` | Se copian de nuevo el JSON original (y su `.bak` si existía), verificados por hash. Si no existía `.bak`, se elimina el que haya creado la QA. |
| `CARPETA_SIN_JSON` | Se eliminan solo el JSON, el `.bak` y el `.tmp` creados por la QA; el resto de la carpeta se conserva. Si había un `.bak` original, se restaura. |
| `SIN_CARPETA` | Se eliminan esos mismos archivos y, si la carpeta queda vacía, también la carpeta. Si contiene otros archivos, se conserva intacta. El juego volverá a empezar sin progreso, igual que antes de la QA. |

- Editar el JSON **solo con el juego detenido**: `CGStore` guarda los datos en memoria y los sobrescribe al guardar. Si Unity tiene desactivada la recarga de dominio al entrar en Play, reiniciar el editor tras editar el JSON.
- No borrar `$bk` hasta comprobar que, tras restaurar, el mapa muestra el progreso personal original. Si el paso 3 se detiene con un error, **no borrar nada a mano**: revisar el mensaje y, si hace falta, copiar los archivos de `$bk` manualmente.
- Registrar en el PR la ruta del respaldo y la confirmación de la restauración (sección 7).
